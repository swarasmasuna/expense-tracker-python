💰 Expense Tracker (Python)

A simple command-line Expense Tracker built using Python to manage daily income and expenses.

📌 Description

This project helps users keep track of their financial activities by allowing them to record income and expenses, view transaction history, and calculate their current balance. It is a beginner-friendly project that demonstrates core Python concepts like lists, loops, and conditionals.

🚀 Features
➕ Add Income
➖ Add Expense
📜 View Transactions
💰 View Current Balance
❌ Exit Program
